Sykemeter
=========

Sykemeter is an automated surf forecast page for a fixed surf spot near One Tree
Island. It combines offshore NOAA GFS Wave forecast data, a local SWAN-derived
wave transfer matrix, wind conditions, and predicted tide data to produce a
browser-ready seven-day forecast.

Forecast Inputs
---------------

- NOAA GFS Wave: offshore wave height, peak period, wave direction, wind speed,
  and wind direction at the nearest model grid point.
- SWAN wave transfer matrix: translates offshore wave height to the nearshore
  surf spot using modelled representative wave cases.
- Predicted tide data: matched to the forecast window and plotted at high time
  resolution.

Wave Transfer Matrix
--------------------

The transfer matrix was derived from One Tree Island South wave observations.
Historic wave records were filtered for outliers, then representative offshore
conditions were selected with a maximum-dissimilarity algorithm. K-means average
cases were retained as an additional comparison. The MDA and K-means average
cases were run through SWAN over the rotated local bathymetry grid at low, mid
and high tide by adjusting the model depth by -1.5 m, 0 m and +1.5 m. At the
surf spot, the transfer coefficient is:

    spot Hs / offshore Hs

The sparse SWAN case outputs were interpolated across circular wave direction,
log-scaled peak period and tide level using a smoothed radial-basis-function
surface. The forecast code matches each GFS forecast time to the predicted tide,
then interpolates between the low-, mid- and high-tide 24 by 18 matrices before
calculating spot Hs.

Main Files
----------

- surf_forecast.py: downloads/processes forecast data and generates the final
  forecast SVG.
- wave_transfer_matrix.txt: mid-tide SWAN-derived transfer matrix retained for
  compatibility.
- wave_transfer_matrix_swan_derived_tide_*.txt: low-, mid- and high-tide
  transfer matrices used by the forecast pipeline.
- generate_site.py: GitHub Actions entry point for generating the public SVG.
- docs/index.html: GitHub Pages webpage.
- docs/final_surf_forecast.svg: current public forecast graphic.
- docs/assets/: supporting figures explaining the wave-transfer method.
- docs/swan_model_explorer.html: interactive SWAN model-output explorer.
- docs/assets/swan_model_explorer_data.json: compact display data for the
  explorer, including Hs, Hs/offshore, period, direction, depth and sparse PDIR
  arrows.

Updating the Public Page
------------------------

The page text and figure references are edited directly in docs/index.html. The
forecast graphic is generated by surf_forecast.py and written to
docs/final_surf_forecast.svg. Supporting images for the explanatory section are
stored in docs/assets/.

If uploading through the GitHub web browser, replace the edited files in the
same paths shown above, then commit the changes. GitHub Pages will serve the
updated docs/ content after the commit is processed.
